# SecretLock 文件夹加密工具

该项目提供一个简洁的桌面程序，用于对**指定文件夹的顶层文件**进行加密/解密（不包含子文件夹内文件）。适用于需要对单个文件夹快速加锁的场景。

## 功能概述

1. **拖入/选择文件夹**：支持拖拽文件夹到程序中（若系统未安装拖拽库，可通过按钮选择）。
2. **为文件夹设置独立密码**：首次加密时设置密码。
3. **加密范围**：仅加密文件夹顶层文件，不遍历子文件夹。
4. **撤回加密**：输入密码即可解密并恢复原文件。
5. **忘记密码**：输入权限词 `itaria277` 即可解除密码并解密。
6. **权限声明**：保留最高修改与解析权限，并保留后续优化修改与功能添加的权利。

## 运行方式

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 运行程序：
   ```bash
   python secretlock.py
   ```

## 使用说明

- **加密**：选择/拖入文件夹，输入密码后点击“加密文件夹”。
- **解密**：选择/拖入文件夹，输入密码后点击“解密并打开”。
- **忘记密码**：点击“忘记密码”，输入权限词 `itaria277` 即可解密。

## 重要说明

- 程序会在文件夹内生成 `.secretlock_meta.json` 作为元数据。
- 已加密文件将变为 `.slk` 扩展名。
- 仅对**顶层文件**处理，子文件夹不受影响。
